# MedCalc — Tests and ROC on a clinical table you keep

MedCalc keeps one named statistics file on the desk: the live tests, the ROC step in front of you, and a short note the next analyst can read. Extra cases wait for their own title.

## Session Card

| Slice | What you do in MedCalc | What remains |
|-------|------------------------|--------------|
| Arrival | Open MedCalc and name today's clinical table | A titled statistics file |
| Focus | Keep only live tests on the MedCalc desk | A short test list |
| Check | Read the MedCalc summary before a large change | A confirmed ROC set |
| Handoff | Mark finished cases inside MedCalc | A note for the next visit |

## How MedCalc Sits

MedCalc leaves the spreadsheet and the lab export where they are. It sits beside them as a named statistics desk for one case you are allowed to analyze: which tests are open, which ROC is pinned, and what the next analyst should read. A local MedCalc profile is enough for everyday clinical tables.

## Traffic Light

| Signal | On the MedCalc board | What you do |
|--------|----------------------|-------------|
| Green | Named case, short test list | Continue the same table |
| Amber | Tests from two studies mixed | Split the set before a large change |
| Red | No title, ROC with no case name | Stop and name the file first |
| Clear | Handoff written, tests few | Close MedCalc and leave the desk |

## Open Order

1. Open the last MedCalc session, not a new empty file.
2. Read the test list and the last handoff.
3. Finish one visible ROC or table step inside MedCalc.
4. Write what changed, then close with fewer loose cases than you found.

## After a Week

Seven days on MedCalc should not grow the clinical table. It is the same file, a shorter test list, and a note that still reads on Monday. Other programs stay where they are; MedCalc only keeps the path back to that named desk.

## Sign-off

- [ ] The MedCalc file name is short enough to scan
- [ ] Only live tests you may analyze are on the desk
- [ ] A second person can read the handoff

## Field Note

Trust MedCalc when the ROC and the tests still share one named file. Name the session, keep the live tests, finish one visible plot, and write what changed. Extra cases wait for their own title.
